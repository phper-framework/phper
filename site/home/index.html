PHPER

PHP Enjoy Rust

Rust ❤️ PHP

The framework that allows us to write PHP extensions using pure and safe Rust whenever possible.

Get Started GitHub 
$ cargo add phper

Features

Pure and safe Rust

Register functions, classes, interfaces, enums, constants and ini settings with safe Rust APIs instead of C macros.

PHP 7.1 to 8.6

Supports PHP 7.1 to 8.6, NTS and ZTS builds, with or without debug.

Linux and macOS

Runs on Linux and macOS, in both the CLI and FPM SAPIs.

The Rust ecosystem

Bring crates from crates.io to PHP, like reqwest for an HTTP client.

Hello world

A PHP function written in Rust. The full walkthrough is in the quick start.

Requirements

  • libclang 9.0 or later
